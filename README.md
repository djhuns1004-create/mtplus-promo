# 먹튀플러스 V7 LIVE FEED

## 변경사항
- 상단 메뉴: 홈 / 먹튀검증 / 보증업체 / 메인 커뮤니티 / 배너문의
- 커뮤니티, 이용가이드 메뉴 제거
- 먹튀검증 메뉴는 mtplss.com 먹튀신고 게시판으로 직접 연결
- 보증업체 메뉴는 mtplss.com 공식보증업체 게시판으로 직접 연결
- 배너문의는 Telegram @mtplus24 연결
- 메인 하단에 먹튀신고/보증업체를 서로 다른 색상으로 구분
- GitHub Actions가 6시간마다 두 게시판을 읽어 data/feed.json 갱신
- 공지글은 자동 제외
- 기존 19개 보증업체 롤링 배너 유지

## 업로드
ZIP 내부 파일/폴더를 GitHub 저장소 루트에 그대로 덮어쓰세요.
.github 폴더도 반드시 같이 업로드해야 자동 동기화가 동작합니다.

## GitHub Actions
저장소 Actions 탭에서 'Sync MTPlus content'를 한 번 수동 실행하면 즉시 최신 목록으로 갱신됩니다.
이후에는 6시간마다 자동 갱신됩니다.
