먹튀플러스 이용안내

각 메뉴를 선택하면 먼저 안내 페이지가 열리고, 내용을 확인한 뒤 이동하기 버튼을 통해 공식 페이지로 이동할 수 있습니다.

1. 가입머니

가입머니 관련 기본 조건과 주의사항을 먼저 확인한 뒤 관련 게시판으로 이동할 수 있습니다.

2. 꽁머니

꽁머니 관련 이벤트 조건과 확인사항을 살펴본 뒤 관련 게시판으로 이동할 수 있습니다.

3. 보증업체

보증업체 페이지에서는 배너와 안내를 확인한 뒤 공식보증업체 게시판으로 이동할 수 있습니다.

4. 메인 커뮤니티

먹튀플러스 소개 페이지에서 사이트 안내를 확인한 뒤 공식 메인 커뮤니티로 이동할 수 있습니다.

외부 페이지 이용 전에는 해당 페이지의 최신 정책과 안내 내용을 직접 확인하세요.
