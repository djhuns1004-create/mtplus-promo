먹튀플러스 이용안내

먹튀플러스 안내 페이지는 원하는 정보를 빠르게 찾을 수 있도록 메뉴별로 구성되어 있습니다.

1. 공식보증업체 확인

보증업체 메뉴에서는 먹튀플러스가 안내하는 공식보증업체 페이지로 이동할 수 있습니다. 배너와 세부 조건은 메인 커뮤니티에서 최신 내용을 확인하세요.

2. 최신 정보 확인

이벤트나 이용 조건, 운영 정책은 변경될 수 있으므로 이용 전에는 메인 커뮤니티에 게시된 최신 공지와 세부 안내를 확인하세요.

3. 문의

추가 문의가 필요한 경우 먹튀플러스 메인 커뮤니티의 공식 문의 수단을 이용하세요. 개인정보나 금융정보는 공개 게시판에 올리지 않는 것이 좋습니다.
